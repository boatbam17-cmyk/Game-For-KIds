# 🏰 ผจญภัยอาณาจักรพยัญชนะไทย (Thai Consonant Kingdom Adventure)

เว็บเกมการศึกษาสำหรับนักเรียนชั้นอนุบาลศึกษาปีที่ 3 (อายุ 5–6 ปี) ออกแบบด้วยภาพการ์ตูนสดใสน่ารัก ปุ่มขนาดใหญ่พิเศษ ตัวหนังสือชัดเจน เล่นง่าย มีเสียงอ่านภาษาไทย และรองรับการแสดงผลทั้งบนโทรศัพท์มือถือ แท็บเล็ต และคอมพิวเตอร์

## 🌟 จุดเด่นและรูปแบบเกม

1. **การเดินทาง 10 ด่านสู่ปราสาทพยัญชนะ**:
   - ผู้เล่นเป็นนักผจญภัยน้อย (เลือกตัวละครเด็กชาย 👦🎒 หรือเด็กหญิง 👧🎒 ได้)
   - มีแถบแผนที่ผจญภัยก้าวข้ามหิน 10 จุด มุ่งหน้าสู่ปราสาทพยัญชนะ
2. **คำถาม 10 ข้อตามแบบเรียนปฐมวัย**:
   - ตัวเลือก 3 ข้อแบบสุ่มตำแหน่งทุกครั้ง
   - ภาพการ์ตูนประกอบเวกเตอร์ SVG สีสันสดใส คมชัดทุกขนาดหน้าจอ
   - ปุ่มอ่านโจทย์ออกเสียงภาษาไทย (Web Speech API) ชัดเจน เหมาะกับเด็กที่ยังอ่านหนังสือไม่คล่อง
3. **ระบบการเรียนรู้เชิงบวก (Positive Reinforcement)**:
   - **ตอบถูก**: แสดงคำชม ป๊อปอัปดาววิ้งวับ ได้รับ 1 ดาว และก้าวไปด่านถัดไป
   - **ตอบผิด**: แสดงคำใบ้ที่เข้าใจง่าย **ไม่หักคะแนน ไม่เปลี่ยนด่าน และให้ตอบใหม่ได้ทันทีจนกว่าจะถูก**
4. **สรุปผลและรับเกียรติบัตร (Certificate of Achievement)**:
   - แสดงคะแนนรวม (10/10), จำนวนดาวสะสม (⭐ 10 ดวง), จำนวนครั้งที่พยายามตอบใหม่
   - มีคำประเมินระดับเหรียญเกียรติยศ และปุ่มพิมพ์เกียรติบัตรเก็บเป็นที่ระลึก
5. **ระบบเสียงในตัว 100% (Zero External Dependencies)**:
   - ใช้ Web Audio API สังเคราะห์เสียงประกอบ (เอฟเฟกต์ตอบถูก, ตอบผิด, รับดาว, เฉลิมฉลองชัยชนะ, ดนตรีคลอเบาๆ) โหลดทันที ไม่ต้องโหลดไฟล์ mp3 ภายนอก หมดปัญหาไฟล์เสียงโหลดไม่ขึ้น
6. **เชื่อมต่อ Google Sheets ผ่าน Google Apps Script Web App**:
   - ปลอดภัย ไร้กังวล: ไม่มีการเปิดเผย API Key หรือรหัสลับในฝั่งหน้าเว็บ
   - บันทึกชื่อเล่น คะแนน จำนวนดาว จำนวนข้อที่ตอบผิด และวันเวลาที่เล่นลงชีตอัตโนมัติ
   - มีระบบสำรองข้อมูลในเครื่อง (LocalStorage) เล่นออฟไลน์ได้ 100%

## 📊 ขั้นตอนการตั้งค่า Google Sheets และ Google Apps Script

ระบบนี้ใช้ **Google Sheets ID:** `15IYfST5tLsyXD42vD8zrdovX0QYYYCcSuTPihUWiEMQ`

### ขั้นตอนที่ 1: เข้าสู่สเปรดชีต
1. เปิด Google Sheets ตาม ID ดังกล่าว หรือไปที่ลิงก์:
   `https://docs.google.com/spreadsheets/d/15IYfST5tLsyXD42vD8zrdovX0QYYYCcSuTPihUWiEMQ/edit`

### ขั้นตอนที่ 2: ติดตั้ง Google Apps Script
1. ที่เมนูด้านบนของสเปรดชีต คลิก **ส่วนขยาย (Extensions)** > **Apps Script**
2. ลบโค้ดเดิมในไฟล์ `Code.gs` ทั้งหมด
3. เปิดไฟล์ [`google-apps-script/Code.gs`](file:///c:/Users/Lenovo/Desktop/เกม/google-apps-script/Code.gs) ในโปรเจกต์นี้ คัดลอกโค้ดทั้งหมดไปวางในหน้าต่าง Apps Script
4. กดบันทึก (ไอคอนรูปแผ่นดิสก์ หรือกด `Ctrl + S`)

### ขั้นตอนที่ 3: สั่งให้สคริปต์สร้างชีตอัตโนมัติ (ครั้งแรก)
1. ในหน้าต่าง Apps Script ที่แถบเครื่องมือด้านบน เลือกฟังก์ชัน `setupSheets`
2. คลิกปุ่ม **เรียกใช้ (Run)**
3. จะมีหน้าต่างขออนุญาตสิทธิ์การเข้าถึง ให้คลิก **ตรวจสอบสิทธิ์ (Review Permissions)** > เลือกบัญชี Google ของท่าน > คลิก **ขั้นสูง (Advanced)** > คลิก **ไปที่ ... (ไม่ปลอดภัย) / Go to ... (unsafe)** > คลิก **อนุญาต (Allow)**
4. เมื่อฟังก์ชันทำงานเสร็จ ระบบจะสร้าง 2 ชีตใน Google Sheets ของท่านโดยอัตโนมัติ:
   - **`Questions`**: มีโจทย์และเฉลย 10 ข้อพร้อมคำใบ้
   - **`Results`**: ตารางบันทึกผลการเล่นของนักเรียน พร้อมหัวคอลัมน์มาตรฐาน

### ขั้นตอนที่ 4: เผยแพร่เป็น Web App (Deploy)
1. ที่มุมขวาบนของ Apps Script คลิกปุ่มสีน้ำเงิน **ทำให้ใช้งานได้จริง (Deploy)** > **การทำให้ใช้งานได้จริงรายการใหม่ (New deployment)**
2. คลิกไอคอนรูปเฟือง ⚙️ ข้าง "เลือกประเภท" แล้วเลือก **เว็บแอป (Web app)**
3. ตั้งค่าดังนี้:
   - **คำอธิบาย (Description):** `API สำหรับเว็บเกมพยัญชนะไทย`
   - **ดำเนินการในฐานะ (Execute as):** `ฉัน (อีเมลของท่าน)`
   - **ผู้มีสิทธิ์เข้าถึง (Who has access):** `ทุกคน (Anyone)` *(สำคัญมาก: ต้องเลือก Anyone เพื่อให้หน้าเว็บส่งคะแนนเข้ามาได้โดยไม่ต้องล็อกอิน)*
4. คลิก **ทำให้ใช้งานได้จริง (Deploy)**
5. คัดลอก **URL ของเว็บแอป (Web App URL)** ที่ลงท้ายด้วย `/exec` เช่น:
   `https://script.google.com/macros/s/AKfycbx.../exec`

### ขั้นตอนที่ 5: นำ URL มาใส่ในเกม
สามารถทำได้ 2 ช่องทาง:
- **วิธีที่ 1 (แนะนำสำหรับขึ้น GitHub):** เปิดไฟล์ [`js/config.js`](file:///c:/Users/Lenovo/Desktop/เกม/js/config.js) แล้วนำ URL ที่คัดลอกมาวางในตัวแปร `GOOGLE_APPS_SCRIPT_URL`:
  ```javascript
  GOOGLE_APPS_SCRIPT_URL: "https://script.google.com/macros/s/AKfycbx.../exec",
  ```
- **วิธีที่ 2 (ทำผ่านหน้าเว็บเกมได้ทันที):** เปิดเกมในเบราว์เซอร์ แล้วคลิกปุ่ม **⚙️ ตั้งค่า Google Sheets (สำหรับคุณครู)** ที่หน้าแรก วาง URL ลงในช่อง แล้วกด **🔍 ทดสอบการเชื่อมต่อ** และ **💾 บันทึกการตั้งค่า**

   - Repository name: เช่น `thai-consonant-adventure`
   - ตั้งค่าเป็น **Public**
   - ติ๊กถูกที่ **Add a README file** หรือปล่อยว่างไว้ แล้วคลิก **Create repository**
3. ในหน้าคลัง ให้คลิก **Add file** > **Upload files**
4. ลากไฟล์และโฟลเดอร์ทั้งหมดในโปรเจกต์นี้:
   - `index.html`
   - โฟลเดอร์ `css/`
   - โฟลเดอร์ `js/`
   - โฟลเดอร์ `google-apps-script/`
   - `README.md`

7. ภายใต้หัวข้อ **Build and deployment**:

   - คลิก **Save**
8. รอประมาณ 1-2 นาที รีเฟรชหน้า จะปรากฏลิงก์เว็บไซต์ เช่น:

## 🔒 สถาปัตยกรรมความปลอดภัย (Security & Privacy)

- **ไม่มีการเปิดเผยข้อมูลลับ**: ไม่มีการใช้ Google Service Account Private Key หรือ Google Cloud API Key บนฝั่งหน้าเว็บ
- **การแยกส่วนหน้าที่ (Separation of Concerns)**:
  - ฝั่งหน้าเว็บ (Frontend) มีหน้าที่เพียงส่งข้อมูลการเล่น (ชื่อเล่น, คะแนน, ดาว, จำนวนครั้งที่ผิด)
  - Google Apps Script (Backend) ทำหน้าที่เป็นตัวกลางรับข้อมูลและตรวจสอบความถูกต้อง ก่อนบันทึกลงในสเปรดชีต
- **ระบบสำรองออฟไลน์ (Offline Fallback)**: แม้ไม่มีอินเทอร์เน็ต เกมจะยังคงสามารถเล่นได้จนจบ 10 ข้ออย่างสมบูรณ์ และบันทึกคะแนนเก็บไว้ในเบราว์เซอร์ (LocalStorage) ของเครื่องนั้นๆ เพื่อให้คุณครูเปิดดูย้อนหลังได้ตลอดเวลา
